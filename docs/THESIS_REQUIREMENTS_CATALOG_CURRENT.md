# كتالوج المتطلبات التفصيلي

يمثل هذا الكتالوج خط أساس المتطلبات للنسخة الموثقة بتاريخ 2026/08/16. يميز التقييم بين وجود الوظيفة وبين اكتمال التحقق التشغيلي والقبول المؤسسي. ويضيف مولد الأطروحة إحدى أربع حالات موحدة: «منفذ ومتحقق»، «منفذ ولم يكتمل التحقق»، «منفذ جزئياً»، و«مخطط أو مؤجل». لذلك لا تعني الوظيفة المنفذة تلقائياً نجاح جميع اختبارات التكامل أو جاهزية الإنتاج، ويقرأ دليل القبول مع الحالة لا منفصلاً عنها.
