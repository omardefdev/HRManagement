# MIG-007 — Exit / rollback

Exit/rollback path is **required** for incomplete onboarding or pre-wave abort:

| Mode | Use |
|---|---|
| exit-incomplete | Stop before wave; keep audit trail |
| rollback-to-pre-wave | Undo wave prep to pre-onboarding baseline |

Fixture `exit-rollback-pass` proves a lab exercised exit path.
