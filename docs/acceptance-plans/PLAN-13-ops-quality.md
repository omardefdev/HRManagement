# PLAN-13 — النسخ والاستعادة + الأداء + PDF العربي + إعادة بناء التدقيق (AC-34..AC-37)

**التغطية:** AC-34, AC-35, AC-36, AC-37. **الطبقة:** 4. **يعتمد على:** PLAN-00.

## الهدف

إثبات نسخ قاعدة واستعادتها في بيئة منفصلة مع زمن مقاس، وقياس قراءة الموظفين والتصفية بالنطاق تحت حمل متدرّج (p50/p95/p99 + معدل الأخطاء دون ادعاء هدف غير محقق)، وتوليد PDF عربي مختلط بصياغة صحيحة، وإعادة بناء رحلة كاملة من سجل التدقيق عبر CorrelationId.

## الوضع الحالي (منفّذ / فجوة)

- AC-34: [scripts/verify-restore.sh](../../scripts/verify-restore.sh) يستعيد ويطبع `measured_restore_seconds`؛ [docs/BACKUP_POSTGRES.md](../BACKUP_POSTGRES.md), [docs/OPS_DR_TOPOLOGY.md](../OPS_DR_TOPOLOGY.md)؛ `BackupJobsController` يزامن الفهرس فقط (لا ينفّذ pg_dump). فجوة: تمرين استعادة في بيئة منفصلة + فحص العلاقات + أرشفة الزمن.
- AC-35: [perf/k6/lookup-list.js](../../perf/k6/lookup-list.js) وأخواتها؛ `lib/thresholds.js` (p95 فقط)؛ [scripts/nfr-k6-run.ps1](../../scripts/nfr-k6-run.ps1)؛ الأساس [perf/results/baseline-lab/summary.json](../../perf/results/baseline-lab/summary.json) **قالب لا أرقام** (CAP-PERF-01 مؤجّل). فجوة: تشغيل حمل فعلي وتسجيل p50/p95/p99 + معدل الأخطاء.
- AC-36: [src/Shared/HRManagement.Documents.QuestPdf/](../../src/Shared/HRManagement.Documents.QuestPdf/) بخط Noto Sans Arabic مضمّن + RTL؛ تقارير (عهدة/موظف/قسيمة)؛ اختبارات `ArabicPdfGenerationTests`. فجوة: قائمة قبول بصري لمختلط عربي+إنكليزي+أرقام غير معكوس.
- AC-37: `GatewayAuditMiddleware` + `PolicyEnforcementLedger` + سلسلة تجزئة [scripts/obs-audit-chain-verify.sh](../../scripts/obs-audit-chain-verify.sh). فجوة: `GatewayAuditEntry` بلا حقول جهة/نطاق؛ لا أداة واحدة تعيد بناء الرحلة (مستخدم/جهة/نطاق/قرار/أحداث).

## تغييرات التنفيذ (مهام)

1. **AC-34:** تمرين نسخ/استعادة في بيئة منفصلة مع فحص العلاقات عبر القواعد التابعة وأرشفة `measured_restore_seconds`.
2. **AC-35:** تشغيل حمل متدرّج فعلي على قراءة الموظفين + التصفية بالنطاق، وتسجيل p50/p95/p99 + معدل الأخطاء؛ عدم ادعاء أي هدف غير محقق.
3. **AC-36:** قائمة قبول بصري + تأكيدات لمختلط عربي/إنكليزي/أرقام وجداول غير معكوسة.
4. **AC-37:** إثراء تدقيق البوابة بالجهة/النطاق، وأداة/إجراء يعيد بناء الرحلة عبر `CorrelationId` (مستخدم/جهة/نطاق/قرار/أحداث).

## منهج الاختبار

مجموعة `Ac34..Ac37`؛ إعادة استخدام `verify-restore.sh`، `nfr-k6-run.ps1`، `ArabicPdfGenerationTests`، `obs-audit-chain-verify.sh` على الحزمة الحية.

## مخرجات الأدلة

`AC-34/`: خرج الاستعادة + `measured_restore_seconds` + فحص العلاقات. `AC-35/`: `summary.json` بأرقام p50/p95/p99 + معدل الأخطاء. `AC-36/`: ملفات PDF ولقطات المراجعة. `AC-37/`: تقرير الرحلة المُعاد بناؤها بالمعرّف.

## تعريف الإنجاز

استعادة مثبتة بزمن مقاس؛ أرقام أداء مقاسة دون ادعاء زائد؛ PDF عربي صحيح؛ رحلة قابلة لإعادة البناء؛ AC-34..37 = `Pass` (أو AC-35 يُعرض كأرقام مقاسة مع بقاء أهداف الأداء Deferred — CAP-PERF-01).
