# PLAN-07 — الرقم الوطني (خصوصية) + Mass Assignment (AC-26, AC-31)

**التغطية:** AC-26, AC-31. **الطبقة:** 3. **يعتمد على:** PLAN-00.

## الهدف

إثبات أن الرقم الوطني مخزّن مشفّراً والبحث يتم بالبصمة والعرض مقنّع لغير المخوّلين، وأن إرسال خصائص إدارية مخفية ضمن نموذج مستخدم عادي يُتجاهل أو يُرفض دون حالة Mass Assignment.

## الوضع الحالي (منفّذ / فجوة)

- منفّذ (AC-26): تشفير عند الحفظ [EmployeePiiProtectionInterceptor.cs](../../src/Services/HRCore/HR.Core.Infrastructure/Data/EmployeePiiProtectionInterceptor.cs)؛ بصمة `Employee.NationalIdHash` مع فهرس فريد `(TenantId, NationalIdHash)`؛ تقنيع `PiiMask` للتقارير/التصدير؛ إسقاط الوسوم الحساسة في OTel. اختبارات `NationalIdExposureTests`, `Gov001PiiMaskAndRedactTests`؛ ترحيل `PRV001_NationalIdEncryptedStorage`.
- منفّذ (AC-31): اختبار معماري `MassAssignmentArchitectureTests` (منع ربط `BaseEntity`)، وallowlists `[Bind]` (مثل `PayrollRunsController.AddSalaryLine`).
- فجوة **AC-26**: التجسيد يفك التشفير دائماً؛ لا سياسة عرض حسب الدور (مقنّع لغير المخوّل)؛ لا سكربت فحص DB+السجلات للتأكد من غياب النص الصريح.
- فجوة **AC-31**: لا اختبار HTTP موجب يرسل خصائص مخفية (`TenantId`/`IsAdmin`/`ApprovedBy`) ويثبت تجاهلها؛ حالات ربط واسع متبقية في اللوجستيات.

## تغييرات التنفيذ (مهام)

1. **AC-26:** سياسة عرض حسب الدور (تقنيع لغير المخوّل عند العرض، لا التخزين)؛ سكربت `scripts/ac026-scan-pii.*` يفحص قواعد البيانات والسجلات عن الرقم الوطني الصريح ويؤكد البحث بالبصمة.
2. **AC-31:** اختبارات HTTP تُرسل خصائص إدارية مخفية عبر نماذج مستخدم عادية وتثبت التجاهل/الرفض؛ إغلاق أي `[Bind]` واسع أو ربط كيانات خارج المجموعات الممسوحة.

## سيناريوهات القبول (موجب + سالب)

| AC | موجب | سالب |
|----|------|------|
| AC-26 | البحث بالبصمة يعمل؛ العرض للمخوّل كامل | فحص DB/السجلات لا يجد النص الصريح؛ العرض لغير المخوّل مقنّع |
| AC-31 | نموذج مستخدم عادي يُحفظ بالحقول المسموحة فقط | خصائص إدارية مخفية تُتجاهل/تُرفض (لا Mass Assignment) |

## منهج الاختبار

مجموعة `Ac26, Ac31`؛ إعادة استخدام الاختبارات أعلاه، وتشغيل فحص PII على الحزمة الحية.

## مخرجات الأدلة

`acceptance-evidence/AC-26/`: خرج فحص DB/السجلات + استجابة بحث بالبصمة + لقطة عرض مقنّع/كامل. `AC-31/`: طلب يحوي حقولاً مخفية + `after.json` يثبت تجاهلها.

## تعريف الإنجاز

لا نص صريح للرقم الوطني؛ بحث بالبصمة؛ عرض مقنّع حسب الدور؛ لا Mass Assignment؛ AC-26/AC-31 = `Pass`. (مفاتيح إنتاج HSM تبقى Deferred — CAP-PRV-01.)
