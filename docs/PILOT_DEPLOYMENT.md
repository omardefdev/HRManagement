# خطة النشر التجريبي المرجعي

## الهدف
تركيب النظام لدى جهة حكومية متوسطة (500–2000 موظف) كمرجع حي لفتح السوق.

## المتطلبات
- خادم: 16 GB RAM، 4 vCPU، 200 GB SSD
- PostgreSQL 16، RabbitMQ، Keycloak، Docker

## خطوات التنفيذ
1. تشغيل `scripts/deploy-organization.ps1 -OrganizationName "..." -LegalRegime LAW_50_2004`
2. استيراد الهيكل والموظفين عبر **استيراد البيانات**
3. تفعيل الإطار القانوني المناسب في الرواتب
4. تدريب 3 أيام: HR، الرواتب، مديرو الفروع
5. تشغيل تجريبي 30 يوماً مع دعم ميداني
6. جمع خطاب توصية + دراسة حالة

## مؤشرات النجاح
- 95%+ من الموظفين في النظام
- دورة رواتب واحدة مكتملة (حساب → اعتماد → ترحيل)
- إغلاق فترة حضور واحدة مرتبطة بالرواتب
- رضا المستخدمين ≥ 4/5 في استبيان بسيط
