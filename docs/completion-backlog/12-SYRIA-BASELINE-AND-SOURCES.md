# خط الأساس السوري الملزم للبطاقات

**تاريخ القطع المعرفي:** 27 تموز 2026.  
**النطاق:** منظومة موارد بشرية ورواتب للقطاع العام والجهات المرتبطة في الجمهورية العربية السورية.  
**قاعدة الحوكمة:** الخبر الرسمي يثبت وجود قرار أو اتجاه، لكنه لا يحل محل النسخة المنشورة في الجريدة الرسمية أو التعليمات التنفيذية المصدقة عند تحويل النص إلى قاعدة حساب. أي رقم مالي أو مهلة قانونية غير مسلمة من السلطة المختصة يبقى `Blocked-Legal`.

## درجات الثقة

| الدرجة | الاستخدام المسموح |
|---|---|
| A — مصدر حكومي/نص نافذ | أساس تحليل المتطلبات، ثم تطابق النسخة مع الجريدة الرسمية قبل الإنتاج |
| B — تصريح رسمي أو خبر حكومي | يثبت الاتجاه أو النطاق؛ لا تُشتق منه معادلة مالية وحده |
| C — مصدر ثانوي | يساعد على الاكتشاف فقط ويحتاج تصديق الجهة القانونية |
| D — قرار سيادي مطلوب | لا تخمين؛ تبقى البطاقة أو البوابة محجوبة حتى التوقيع |

## الوقائع السورية التي تغيّر التصميم

| المجال | ما ثبت حتى تاريخ القطع | أثره الإلزامي على المشروع |
|---|---|---|
| الخدمة العامة | القانون الأساسي للعاملين في الدولة رقم 50 لعام 2004 وتعديلاته ما زال مرجعاً معلناً لفئات واسعة، مع فئات مستثناة في المادة 159 وأنظمة خاصة | لا يوجد نموذج أجر أو إجازة واحد؛ يلزم `legal_regime_id` مؤرخ لكل علاقة عمل |
| تعدد الأنظمة | المرسوم 67/2026 استثنى المشمولين بالقانون 53/2021 وبعض مستفيدي الزيادات النوعية | محرك قواعد متعدد الأنظمة، ومنع الجمع غير المشروع، ومسار تسوية انتقالية |
| الأجور | المرسومان 67 و68 لعام 2026 وتعليماتهما غيّرا الجداول والزيادات والاستثناءات والتعويضات | كل جدول/تعويض نسخة فعالة بتاريخ، مع مصدر قانوني وتوقيع ومجموعة اختبارات ذهبية |
| التقاعد | المرسوم 135/2026 منح زيادة للمعاشات وربط الحد الأدنى بالحد الأدنى العام للأجور | فصل حساب الراتب عن المعاش، مع قواعد مؤرخة ومصالحة مع مؤسسات التأمين والمعاشات |
| العملة | الليرة السورية الجديدة = 100 ليرة قديمة؛ وابتداءً من 31 تموز 2026 يُقصد بالليرة في التعاملات الرسمية الليرة الجديدة | تخزين العملة والكود والعصر النقدي؛ تحويل دقيق؛ منع خلط القديم والجديد؛ إعادة طباعة كل الوثائق المالية |
| الضرائب | إصلاح ضريبة الدخل المنشور في نيسان 2026 وُصف بأنه مقترح؛ لا يكفي لبناء شرائح نافذة | لا hard-code من الأخبار؛ استيراد جدول مصدق من وزارة المالية مع تاريخ نفاذ واختبارات رجعية |
| العطل | المرسوم 188/2025 حدّد العطل المأجورة وأحال الأعمال المستمرة إلى أحكام خاصة | تقويم مركزي مؤرخ مع تقاويم جهات/ورديات، لا قائمة ثابتة في الواجهة |
| البيانات الشخصية | القانون 12/2024 وتعليماته التنفيذية، وهيئة حماية البيانات الشخصية، ونماذج الترخيص/التصريح ومسؤول الحماية | سجل معالجة، أساس قانوني، حقوق صاحب البيانات، DPO، DPIA، وترخيص/تصريح معتمد قبل البيانات الحقيقية |
| الاستضافة الحكومية | وزارة الاتصالات قيدت جمع البيانات بالنماذج الحكومية أو المنصات المعتمدة؛ والهيئة الوطنية لخدمات تقانة المعلومات توفر مركز المعطيات والاستضافة والنطاقات والشهادات | اعتماد معماري واستضافة واتصالات خروج واسم نطاق وشهادات من الجهات السورية قبل الإنتاج |
| الأمن السيبراني | قانون الجرائم المعلوماتية 20/2022، السياسة الوطنية لأمن المعلومات، والاستراتيجية الوطنية، واللائحة 20 `NAITS/ET` مذكورة رسمياً | ملف مطابقة سوري مستقل، ربط SIEM/SOC، واختبار حادثة وإخطار مع الجهات المختصة |
| الهوية المدنية | السجل المدني مؤتمت مركزياً، وخدمات الأحوال المدنية تتجه للتحقق بالباركود والربط الإلكتروني | السجل المدني مصدر تحقق لا قاعدة يملكها HR؛ يلزم connector بموافقة، مطابقة، وfallback موثق |
| التكامل الحكومي | ناقل البيانات الحكومي والربط الكامل ما زالا ضمن مسار 2025–2030 | دعم API عند الجاهزية، وملفات موقعة/دفعات ومصالحة في المرحلة الانتقالية؛ يمنع ادعاء تكامل حي غير موجود |
| الانتشار | 14 محافظة، مع تفاوت اتصال وخدمات متنقلة ومناطق ذات سجلات وأنظمة إرث مختلفة | تشغيل منخفض النطاق، استئناف آمن، موجات محافظة/جهة، ونقاط مساعدة محلية |
| الحجم | المصادر الرسمية ذكرت قرابة مليون مشترك من القطاع العام ونحو 950 ألف متقاعد/مستفيد، مع أرقام أخرى أضيق نطاقاً | الأرقام تخطيطية لا تعداداً رسمياً؛ `SYR-002` يحسمها. مؤقتاً نختبر 1.25M راتب و2M ضغط و5M سجل شخصي/تاريخي |

## الجهات السورية صاحبة الاعتماد أو البيانات

| الجهة/الدور | القرار أو التكامل المطلوب |
|---|---|
| الجهة الحكومية المالكة + وزارة التنمية الإدارية | نطاق الخدمة، أنظمة العاملين، الهيكل والملاك، ونموذج التشغيل |
| وزارة المالية والخزينة | جداول الأجور والضرائب والتعويضات، أوامر الصرف، المجاميع الرقابية |
| وزارة الشؤون الاجتماعية والعمل | قانون العمل/التأمينات والاشتراكات والحقوق العمالية ضمن الاختصاص |
| المؤسسة العامة للتأمينات الاجتماعية | اشتراكات وسجل المؤمن عليهم ومصالحة الاستحقاقات |
| المؤسسة العامة للتأمين والمعاشات | معاشات الفئات الخاضعة ونقاط الصرف والمصالحة |
| وزارة الداخلية/الأحوال المدنية | تحقق الهوية والوقائع المدنية وحدود الاستخدام |
| وزارة الاتصالات وتقانة المعلومات | اعتماد المنصة وجمع البيانات والتحول الرقمي والسياسة السيبرانية |
| الهيئة الوطنية لخدمات تقانة المعلومات | الاستضافة/السحابة/النطاق/الاعتماد واللائحة 20 وملف التكامل |
| مركز التصديق الإلكتروني الوطني/الحكومي | شهادات الموظفين والخوادم والبرمجيات والتوقيع وسلسلة الثقة |
| هيئة حماية البيانات الشخصية | الترخيص/التصريح/الاعتمادية وDPO والشكاوى ونقل البيانات |
| الجهاز المركزي للرقابة المالية | الضوابط المالية، مسارات التدقيق، الأدلة والمجاميع الرقابية |
| الهيئة المركزية للرقابة والتفتيش | الرقابة الإدارية والتحقيق وسلسلة الأدلة بحسب الاختصاص |
| مصرف سوريا المركزي والمصارف العامة والبريد السوري | كود العملة، ملفات/أوامر الدفع، حالات التسوية والرفض والإرجاع |
| كل وزارة/هيئة/محافظة مشاركة | مالك البيانات، UAT، المفوضيات، وصحة سجلات المصدر |

## الإضافات الملزمة إلى البطاقات الأصلية

| البطاقات الأصلية | الإضافة السورية التي لا يجوز إسقاطها |
|---|---|
| `STR-001`, `CAP-001..003`, `PERF-001` | مغلف سوريا في هذا الملف + نتائج `SYR-002`، مع 14 محافظة وموجات معلنة |
| `STR-002`, `GOV-001..003`, `PRV-001..003`, `LEG-001` | القانون 12/2024، القانون 50/2004، المراسيم النافذة، سجل قواعد ومصدر الجريدة الرسمية |
| `PAY-001..003`, `HCM-001..006`, `EST-001` | `legal_regime_id` و`rule_version_id` و`currency_era` وعدم الجمع بين الأنظمة والاستثناءات |
| `MDM-001..002`, `ORG-001` | أكواد سورية مركزية: الجهة، المحافظة، الوحدة الإدارية، الملاك، الصفة الوظيفية، المصرف/البريد |
| `MIG-001..007` | فصل المصدر والنظام القانوني والمنطقة، عدم الكتابة فوق السجل، وتسوية التكرار عبر الأحوال المدنية |
| `EXT-001..007`, `INT-004`, `IOP-001` | ملفات مطابقة للأحوال المدنية، التأمينات، المعاشات، المالية، المصارف، البريد، ناقل البيانات والتصديق |
| `SOV-001..007`, `SIG-001`, `HARD-001` | اعتماد وزارة الاتصالات والهيئة الوطنية، مركز معطيات/سحابة مصادق عليها، مفاتيح داخل السيادة السورية |
| `L10N-001`, `PROD-004`, `MOB-001`, `UX-001..002` | العربية RTL أولاً، أرقام/تواريخ/عملة سورية، اتصال ضعيف، الوصولية، وسياسة لغات إضافية معتمدة |
| `NAT-001..008` | لا شهادة وطنية من دون إغلاق `SYR-001..017` وتوقيعات الجهات السورية في الملف 14 |

## خط أحمر قانوني

لا تتضمن هذه الحزمة فتوى قانونية ولا تدّعي أن الأخبار بديل عن الجريدة الرسمية. دورها تحويل ما أمكن إثباته إلى متطلبات، وكشف ما يجب أن تسلمه الدولة قبل البرمجة أو الإطلاق. أي تعارض بين هذه الحزمة ونص نافذ مصدق يُحسم للنص، ويصدر له rule pack جديد دون تعديل التاريخ الماضي.
