# سجل القرارات والاعتماد السوري قبل الإنتاج

هذا السجل ليس قائمة أسئلة اختيارية. كل بند غير محسوم يحمل حالة `OPEN-NO-GO` ويمنع `SYR-017` و`NAT-008` في النطاق المتأثر.

## مجلس الاعتماد السوري الأدنى

| المقعد | ما يوقع عليه |
|---|---|
| مالك الخدمة الحكومية | النطاق والموجة والنتيجة العامة |
| وزارة التنمية الإدارية/سياسة الموارد البشرية | أنظمة الخدمة والملاك والوظائف |
| وزارة المالية/الخزينة | الأجر والضريبة والصرف والمجاميع |
| وزارة الشؤون الاجتماعية والعمل | التأمينات والحقوق الواقعة ضمن اختصاصها |
| ممثل التأمينات الاجتماعية | الاشتراكات وسجل المؤمن عليهم |
| ممثل التأمين والمعاشات | المعاشات والمستفيدون |
| الداخلية/الأحوال المدنية | الهوية والوقائع المدنية |
| الاتصالات وNAITS | الاستضافة والتكامل والمطابقة التقنية |
| هيئة حماية البيانات الشخصية/DPO | الترخيص والخصوصية وحقوق الأشخاص |
| مركز التصديق الإلكتروني | التوقيع والشهادات وسلسلة الثقة |
| الجهاز المركزي للرقابة المالية | صحة الضوابط والمصالحة والدليل المالي |
| الهيئة المركزية للرقابة والتفتيش | ضوابط الرقابة والتحقيق بحسب الاختصاص |
| CISO/SOC | الأمن والحوادث والتعافي السيبراني |
| ممثلو الجهات والمحافظات في الموجة | UAT وجودة البيانات وقابلية التشغيل |
| مقيّم مستقل للأمن والأداء والهجرة | شهادة نتائج لا تتبع فريق التطوير |
| مسؤول الاعتماد المخول | قرار `No-Go/Pilot/Wave` محدود النطاق والمدة |

## بيانات إلزامية في قرار الموجة

- release version وsource commit وimage digests وSBOM وrule-pack hashes.
- الجهات والمحافظات والأنظمة القانونية والقنوات المشمولة والمستثناة.
- تواريخ النصوص والتعليمات والعملة والضريبة والتأمين المعتمدة.
- تعداد العاملين والمتقاعدين والدفعات والمبالغ control totals.
- نتائج ثلاث دورات ظل، الأداء، DR، الأمن، الخصوصية، الهجرة والتكامل.
- الاستثناءات الموقعة وتاريخ انتهائها، مع منع الاستثناء عن سلامة الراتب والعزل والمفاتيح والنسخ.
- نافذة الإطلاق والتجميد والرجوع، أصحاب القرار، غرفة العمليات وقنوات الاتصال البديلة.
- تاريخ انتهاء الاعتماد ومشغلات إعادة الاعتماد: قانون/جدول/عملة/CA/بنية/مزود/نطاق جديد.

## حالات No-Go السورية الصريحة

- جدول ضريبة أو اشتراك أو تعويض مصدره خبر أو ملف Excel غير موقع.
- موظف بلا `legal_regime_id` أو جهة بلا مالك بيانات أو سجل بلا مصدر.
- مبلغ بلا `currency_era` خلال فترة الهجرة من الليرة القديمة.
- غموض في نطاق فئات القانون 53/2021 أو الزيادات النوعية يؤدي إلى دفع مزدوج أو حسم غير مصرح.
- غياب ترخيص/قرار هيئة حماية البيانات أو قرار الاستضافة/نقل البيانات.
- تكامل أحوال مدنية أو مصرف أو بريد أو تأمينات بلا اتفاق واختبار مصالحة.
- مفاتيح تشفير أو توقيع يملكها المورد منفرداً أو توجد خارج الوصاية المعتمدة.
- اختلاف مالي واحد غير مفسر، أو سطر دفع بلا نتيجة نهائية، أو إمكانية replay مزدوج.
- فشل محافظة/فرع في الاتصال يؤدي إلى فقد الطلب أو تكراره أو تخزين مكشوف.
- عدم نجاح rollback وDR وclean-room على الإصدار نفسه المقترح للإطلاق.
