# ADR-GOV-001 — تصنيف البيانات والخصوصية والاحتفاظ

| الحقل | القيمة |
|---|---|
| الحالة | Accepted |
| البطاقة | GOV-001 (البطاقة 47) |
| التاريخ | 2026-07-28 |
| DPIA | [GOV_001_DPIA.md](./GOV_001_DPIA.md) — **Approved** (منصة) |

## السياق

توجد ضوابط جزئية (AuditRedact، legal hold، anonymize، purge تدقيق) بلا جرد حقول بمالك/غرض/مدة، بلا DPIA منصة، بلا DSAR workflow، وبلا سياسة non-prod إلزامية.

## القرار

| الموضوع | الاختيار |
|---|---|
| جرد | `docs/data-classification/inventory.json` + Markdown |
| احتفاظ | جدول موحّد + dry-run؛ التنفيذ عبر الخدمات الحالية و`AllowPurge` |
| تصدير | قناع الرقم الوطني (`PiiMask.NationalId`) في CSV/Excel العام |
| Non-prod | سياسة + بوابة ملفات dump |
| DSAR | كيان/API في Compliance (Access/Rectify) |
| خارج النطاق | GOV-002/003، PRV/NAT شهادات، L10N |

## التقليل (minimization)

يُجمع: هوية وظيفية، اتصال، طبي عند الحاجة، راتب، شكاوى. لا يُصدَّر الرقم الوطني كاملاً في تقارير عامة؛ التدقيق يخفي الحقول الموسومة.

## العواقب

- تصدير الموظفين يعرض قناعاً لا الرقم الكامل.
- DSAR v1 يجمّع اكتشافاً من HRCore أساساً؛ التكامل الكامل عبر الخدمات = PRV لاحقاً.
