# دليل المستخدم — منظومة الموارد البشرية الحكومية

## 1. البدء
- الدخول عبر البوابة المركزية `/` باستخدام حساب Keycloak.
- اختيار الوحدة من لوحة التحكم (الموظفون، العقود، الرواتب...).

## 2. الهيكل التنظيمي والفروع
- إدارة الشجرة من **الوحدات التنظيمية**.
- مستخدمو دور `branch-manager` يرون بيانات فرعهم والوحدات التابعة فقط.
- المركز (أدوار `hr-admin` / `hr-core`) يرى كل البيانات.

## 3. الرواتب والأطر القانونية
- من **الأطر القانونية للرواتب** اختر الإطار الفعّال (قانون 50 أو الخدمة المدنية).
- عدّل الشرائح والعطل ومعادلة نهاية الخدمة حسب التشريع المعتمد.

## 4. الحضور
- تسجيل يومي أو **إدخال جماعي** شهري لكل وحدة.
- عند اعتماد الإجازة تُنشأ سجلات حضور `OnLeave` تلقائياً.
- **إغلاق فترة الحضور** ينشر ملخصاً للرواتب لخصم الغياب.

## 5. بوابة الموظف
- المسار: `/ui/ess/EssPortal`
- دور `hr-employee`: عرض الملف، الحضور، روابط طلب إجازة وملف الراتب.

## 6. الاستيراد الأولي
- **استيراد البيانات** من CSV للوحدات والموظفين عند الترحيل من النظام الورقي.

## 7. التركيب والنسخ الاحتياطي
- `scripts/deploy-organization.ps1` للنشر لكل جهة.
- `scripts/backup-all-databases.ps1` للنسخ الاحتياطي اليومي.
