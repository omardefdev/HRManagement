# كتالوج المتطلبات التفصيلي

يمثل هذا الكتالوج الصياغة المنظمة لمتطلبات النظام. تشير الحالة «منفذ في v1» إلى أن المتطلب دخل ضمن نطاق الإصدار الأول وخضع لمعيار قبول أو تحقق موثق، أما «مؤجل» فتشير إلى متطلب معتمد خارج نطاق هذا الإصدار ولا يعرض بوصفه وظيفة مكتملة.

## المتطلبات غير الوظيفية

| الرمز | المحور | المطلب القابل للتحقق | دليل القياس أو الحالة |
|---|---|---|---|
| NFR-01 | الأمان | كل مسار إداري محمي بالمصادقة والتفويض | سياسات Keycloak وGateway |
| NFR-02 | العزل | يمنع الفرع من الوصول إلى فرع شقيق | اختبارات نطاق + اختبار E2E عند توفر البيئة |
| NFR-03 | الخصوصية | عزل الصحة والرواتب والامتثال في خدمات وقواعد مستقلة | مخطط ملكية البيانات |
| NFR-04 | التدقيق | يسجل كل تغيير حساس الفاعل والوقت والمرجع | AuditableEntity وسجلات التدقيق |
| NFR-05 | الأسرار | تحفظ أسرار التشغيل خارج ملفات التطبيق ويمنع تثبيتها ضمن حزمة التسليم | مراجعة الإعدادات ومتغيرات البيئة قبل النشر |
| NFR-06 | التتبع | يمر Correlation ID بين HTTP والرسائل | CorrelationIdFlow واختباراته |
| NFR-07 | الاعتمادية | يعاد نشر الرسائل الفاشلة وفق سياسة retry | MassTransit retry وfault logging |
| NFR-08 | عدم التكرار | لا تعالج الرسالة نفسها مرتين في المستهلكات الحرجة | IntegrationMessageReceipts |
| NFR-09 | الاتساق | تسجل آثار العملية العابرة للخدمات كأحداث قابلة للتتبع | Outbox/Event matrix |
| NFR-10 | التشغيل | توفر كل خدمة health endpoint | HealthChecks على الخدمات |
| NFR-11 | النشر | يمكن بناء البيئة عبر Docker Compose | ملفات compose وrunbook |
| NFR-12 | الأداء | يقاس زمن الاستجابة للحالات المحددة تحت حمل معلن | نتيجة k6 أو حالة غير مقاسة |
| NFR-13 | التوسع | يمكن توسيع خدمة دون مشاركة قاعدة خدمة أخرى | Database per Service |
| NFR-14 | الصيانة | تفصل الطبقات وقواعد المجال عن الواجهة | بنية المشاريع واختبارات القواعد |
| NFR-15 | التوافق | تحفظ عقود الأحداث الإصدار SchemaVersion | MessageContracts |
| NFR-16 | النسخ الاحتياطي | توثق نسخة PostgreSQL لكل قاعدة وخطوة استعادة | BACKUP_POSTGRES وrunbook |
| NFR-17 | التعافي | يحدد RPO/RTO بعد اعتماد المؤسسة، ولا يعلن كرقم مقاس دون تجربة | قيد معلن وخطة اختبار |
| NFR-18 | الواجهات | تستخدم الواجهات العربية RTL في المسارات المدعومة | UI checklist ولقطات |
| NFR-19 | الاختبار | كل قاعدة مجال جوهرية مرتبطة باختبار آلي | 491 اختبار وحدة وتغطية لاحقة |
| NFR-20 | القابلية للمراقبة | تسجل الخدمة الأخطاء ومؤشرات الصحة دون بيانات حساسة | Serilog/OpenTelemetry ومراجعة السجلات |
