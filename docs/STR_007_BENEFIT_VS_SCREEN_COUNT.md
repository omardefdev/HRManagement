# STR-007 — Benefits are not screen counts

**Forbidden benefit measures:** `screenCount`, `pageCount`, `widgetCount`.

Success and competition claims must use catalog KPIs (cycle time, adoption, DQ, CSAT, uptime, unit cost stubs, onboarding). Counting UI surfaces, menus, or widgets as “value delivered” fails validate (`screen-count-banned` fixture).

UI inventory may exist for UX work (UXR/PROD) but is **not** a STR-007 benefit metric.
