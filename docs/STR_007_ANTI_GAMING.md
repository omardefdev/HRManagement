# STR-007 — Anti-gaming rules

| Category | Example rules |
|---|---|
| Cycle time | Exclude cancelled offers; no silent backdates; lock definition per quarter |
| Self-service | Eligible set signed; do not coerce denials to inflate rate |
| DQ / duplicates | No silent close of open cases; thresholds from GOV-003 |
| CSAT | Minimum response rate; no cherry-picked agencies |
| Uptime | Use OBS SLO window; maintenance exclusions need change ticket |
| Cost | Include ops/security/backup; forbid dev-only cost (align STR-006) |
| Adoption | Active = ≥1 txn in period; entitled set from STR-003 |

Invariant: `ownerRole ≠ auditorRole` on every KPI. Quarterly reviews must cite these rules.
