# Offboarding checklist (SCM-001)

- [ ] Remove from GitHub organization
- [ ] Remove from CODEOWNERS / teams
- [ ] Revoke SSH / GPG keys and PATs
- [ ] Disable Keycloak / IdP developer account
- [ ] Revoke VPN / bastion
- [ ] Rotate shared secrets the person could access
- [ ] Confirm no open PRs mergeable by departed account
- [ ] Log completion time (SLA: 1 business hour)
