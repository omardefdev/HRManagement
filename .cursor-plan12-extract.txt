## W12.2 — حراس نطاق العهدة + فلتر القوائم (AC-32)

**قاعدة النطاق (من PLAN-12):** `Asset` بلا `OrgUnitId` — **مرساة النطاق** = موظف الحائز النشط (`AssetAssignment` مفتوح `Active`/`PendingApproval`)؛ إن لم يوجد حائز → **Unrestricted فقط** (مركز/HR) يعدّل؛ الفرع الشقيق **403**.

**خطوات:**

1. إنشاء `AssetOrgScopeGuard` في `Admin.Logistics.Web/Helpers/` (أو `HRManagement.ServiceDefaults` إن أُريد إعادة استخدام):
   - `ResolveAnchorEmployeeIdAsync(assetId)` — open assignment → `EmployeeId`
   - `ForbidIfAssetOutOfScopeAsync(Controller, User, assetId, db snapshots)` — يستدعي `EmployeeOrgScopeGuard` على المرساة؛ إن لا مرساة و`MustFilter` → `Forbid()`
   - `ForbidIfEmployeeOutOfScopeAsync` على `employeeId` في `AssignToEmployee` (منع إسناد لموظف خارج النطاق)
2. توصيل الحراس في [AssetsController.cs](src/Services/AdminLogistics/Admin.Logistics.Web/Controllers/AssetsController.cs):
   - `Details`, `Edit` (GET/POST)
   - `AssignToEmployee`, `ReturnAssignment`, `MarkLost`, `RecoverAsset`, `CancelAsset`
   - `HandoverReceiptPdf` (قراءة حساسة)
3. فلتر `Index` في `AssetsController`: join open assignments → employee snapshot → `WhereInOrgScope` ([OrgScopeControllerExtensions.cs](src/Shared/HRManagement.ServiceDefaults/OrgScopeControllerExtensions.cs))؛ الأصول غير المُسنَدة تظهر لـ Unrestricted فقط.
4. [AdminExtendedControllers.cs](src/Services/AdminLogistics/Admin.Logistics.Web/Controllers/AdminExtendedControllers.cs) — `AssetAssignmentsController.Index/Details`: فلتر عبر `EmployeeId` snapshot.
5. رسائل الرفض: redirect + TempData (نمط UX الحالي) للـ MVC؛ **403** للطلبات API إن وُجدت.

```mermaid

  participant User as BranchManager_BR2

  Guard-->>User: 403 Forbid
```

**تحقق W12.2:** مستخدم `branch-mgr-br2` (من PLAN-00 personas) يحصل 403 على عهدة `emp-br1`؛ `branch-mgr-br1` و`hr-center` ينجحان.
